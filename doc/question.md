### while 循环
##### 问题1：
```lua
t5(82139);
int end = 1000;

t1(78);
```
还有：
```lua
t5(82139);

int end = 1000;
t1(78);
```
这种情况下会报错！
但是：
```lua
t5(82139);
int end = 1000;
t1(78);
```
或者这样：
```lua
t5(82139);
int end = 1000;


t1(78);
```
....
都不会报错

大概是call的AST解析边界eat错误
